# 文档维护约定

文档与源码一起维护，当前文档标记软件版本，历史文档保留在 `docs/archive`。验收前不推送远程Git仓库。

2026年11月4日用户已追加授权：当前0.1.1推送到公开GitHub仓库并部署GitHub Pages。本次发布按该授权执行，保留完整验收尚未通过及真机未测的记录；不能把发布成功视为功能验收全部通过。发布前快照保存在 `archive/v0.1.1/before-github-pages-20261104`。

每次修改按以下顺序处理：

1. 明确行为或范围变化，更新产品需求或技术方案中的对应段落。
2. 修改实现与必要的规则、配置或素材说明。
3. 执行与变化相关的检查，在验收记录中写明版本、结果和限制。
4. 在CHANGELOG新增具体变更，记录对玩家的影响。
5. 进入下一版本前，归档上一版当前文档；旧验证报告带上版本或另存，不能静默改写旧版验收结论。

版本约定：0.1.x用于当前第一版修复和小幅调优；新增独立模式或显著改变玩法时升级次版本。正式版本号由项目package.json统一记录。

不把计划写成已实现，不把模拟触控写成真机测试，不把一次固定种子通关写成任意随机序列都可通关。对手感、实际声音和真实手机浏览器安全区域，保留用户验收结果。

项目根目录的AGENTS.md包含同样的维护要求，方便后续开发继续遵守。
