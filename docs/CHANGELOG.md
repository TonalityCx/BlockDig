## 0.1.0 2026年11月4日

首次本地试玩版本。

- 建立E盘Cocos Creator 3.8.8与TypeScript工程，网页构建与本地预览脚本。
- 完成七种方块、随机袋、旋转修正、落点虚影、暂存、三块预告、软降、硬降与锁定延迟。
- 完成30米有限地层、消行压实、按清除地层数补层、铜矿和水晶、分数、通关及堆顶失败。
- 完成首页、首次说明、设置、对局、暂停与二次确认、结算及再次挑战。
- 加入按住重复、多点触控、滑出取消、硬降防连发、切后台暂停与继续倒计时。
- 加入像素矿洞画面、基础消行反馈、程序生成音效、本机纪录与设置。
- 建立docs当前文档、历史归档、规则附表、自动化报告及持续更新约定。
- 通过18项规则与存储测试、TypeScript检查、固定种子30米通关回放及18项浏览器检查。实际手机手感、声音和性能仍等待用户验收。

范围保持为手机网页；本版没有微信接入、业务后端、账号、公网发布或Git推送。

本轮修复：连续移动的迭代器编译兼容、桌面键盘事件、小屏预告与计时重叠、小屏结算文字靠近按钮，以及试玩端口与编辑器预览冲突。正式构建裁剪了未使用的引擎模块。
