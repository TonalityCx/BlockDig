# 手机界面与素材

适用软件版本：0.1.0。

## 页面

首页显示矿工与矿石像素插画、第一矿井目标、开始入口、说明、设置和本机纪录。首次开始先显示三步说明，完成后记录已读状态；说明可从首页重新打开。

对局从上到下为标题与暂停、深度与得分、棋盘和紧凑预告、触控按钮。棋盘完整显示20行，保持1比2比例；预告三块，暂存位于棋盘右上方，计时位于右下方。空间优先分配给完整棋盘与至少44像素的触控区域。

暂停保留当前对局，可继续、重新开始、进入设置或返回首页。重新开始与返回首页需确认；取消后仍暂停。继续倒计时三秒。横屏时显示转回竖屏的提示。

结算展示通关或失败、分数、深度、用时、铜矿和水晶数，并提供再次下潜和返回首页。

设置支持声音和减少动态效果。本机存储不可用时保留游戏能力并给出纪录保存提示。

## 布局

以浏览器实际可见宽高计算布局，读取CSS安全区域。棋盘、按钮和文字使用同一套引擎坐标；浏览器工具栏改变高度时重新布局。横竖屏变化或对局中resize会暂停，避免布局变化造成误操作。

基础目标视口为360×640、390×844、430×932 CSS像素。下方按钮分两排，第一排左移、软降、右移、旋转，第二排暂存与独立的金色落底按钮。左右移动和软降支持按住，多点触控分别维护手指状态；手指移出或取消后解除按住。

## 美术规格

| 元素 | 当前实现 |
| --- | --- |
| 背景 | 深藏蓝与灰蓝像素岩壁，少量暖色微光 |
| 方块 | 七种颜色、明暗边缘与中心纹理，位置和形状优先清晰 |
| 地层 | 岩灰方格与裂纹，缺口保持空白 |
| 铜矿 | 岩格内的金铜色颗粒 |
| 水晶 | 岩格内的青绿色多边形及高光 |
| 落点虚影 | 低亮度描边，不与已落定方块混淆 |
| 主按钮 | 暖金色、像素式边缘和按下反馈 |
| 中文文字 | 浏览器sans-serif字体，关键数字和标题加粗 |
| 首页插画 | 使用引擎图形绘制的矿工、矿井和水晶 |

当前画面由项目代码绘制，不依赖外部图片链接。8个短音效由 `tools/make-audio.cjs` 生成，分别用于按钮、移动、锁定、消行、采矿、区域、通关和失败。

实际手机的字体、音频输出和触控舒适度仍需验收；自动化截图仅用于确认布局和状态。

当前实现包含矿石飞向收集位置、补地层的短暂平移，以及桌面竖屏试玩容器。小屏自动压缩预告卡与结算排版，保持主要操作按钮的触控范围。
