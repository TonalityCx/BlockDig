## 核对结论

当前定制画面和音效均在本次开发中通过代码制作。未从素材网站购买或下载图片、图标、音乐或字体包，未导入其他游戏的美术资源，也未使用ImageGen生成图片。

这是一份资源来源记录，不是整款游戏的法律清权结论。代码与图案由AI辅助编写，不据此承诺排他权、著作权登记状态或绝对不会与第三方作品相似。游戏名称、商标及整体玩法呈现的权利判断不在本次素材来源核对范围内。

## Cocos许可与引擎资源

当前使用的Cocos Engine 3.8.8根许可证为MIT，要求在软件副本或实质部分中保留版权和许可声明。[对应版本许可证](https://github.com/cocos/cocos-engine/blob/v3.8.8/LICENSE.md)。

项目保留该许可证的原始文本于licenses/Cocos-engine-MIT.txt。构建后脚本将其复制到网页发布包的licenses目录，避免后续重新构建时丢失。

Cocos Creator编辑器另有自己的软件许可，不能把运行时MIT许可理解为对编辑器、商标及所有依赖的统一授权。[对应版本编辑器协议](https://github.com/cocos/cocos-engine/blob/v3.8.8/licenses/EDITOR_license_and_terms_en.txt)。

本项目会使用引擎运行时及必要的内置渲染资源；这些与上表中本次编写的定制图案分开记录。本次没有完成整个引擎、引导脚本和开发工具依赖树的逐项许可证审计，因此不宣称已经完成商业发行所需的全面清权。
