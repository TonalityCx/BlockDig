# 方块深掘产品需求文档

版本：0.1.1  
日期：2026年11月4日  
用途：确定第一版产品范围，供玩法评审、界面设计、开发和验收使用。

当前版本按用户确认的v0.1方向开始开发，采用本文建议作为第一版实现基线。初始手感参数保留调优空间。精确规则、关卡矩阵与验证证据见规则与关卡文档；实际完成与待验收状态见验收记录。项目名称方块深掘仍为暂定名。

## 1 产品定位与已确认方向

做一款手机浏览器中游玩的竖屏方块消除游戏。在传统俄罗斯方块的移动、旋转、下落、消行基础上，加入地下挖掘：消除地层，收集矿石，抵达目标深度后通关。

核心体验是同时处理两件事：保持堆叠安全，以及规划怎样消除地层取得更深处的矿石。新机制围绕落块与消行展开。

| 项目 | 状态 | 内容 |
| --- | --- | --- |
| 首发平台 | 已确认 | 手机网页版 |
| 主要输入 | 已确认 | 触控操作 |
| 主模式 | 已确认 | 闯关挖掘，到达目标深度通关 |
| 玩法方向 | 已确认 | 传统方块消行与地层挖掘结合 |
| 美术方向 | 已确认 | 精致像素风与地下矿洞，带温暖的探险感 |
| 界面布局 | 当前实现 | 竖屏，顶部状态、中部棋盘、底部触控区 |
| 第一版内容 | 当前实现 | 一个完整关卡，包含三种地下区域的视觉变化 |
| 账号与成长 | 当前实现 | 无账号，保存本机成绩和设置，无永久升级 |

### 1.1 本轮开发约束

以下内容已在需求草案后续讨论中确认：

- 本轮只交付手机网页版。微信小程序或小游戏仅为未来设想，本轮不进行微信构建、接口接入或平台验证。
- 项目源码存放在E盘，计划使用独立目录 `E:\BlockDig`，避免覆盖已有工程。
- 验收前进行本地开发与测试；用户验收通过后，再整理并推送到Git仓库。
- 先完成本机可运行、手机可试玩的版本；公网发布与远程仓库不作为启动前提。

## 2 第一版目标和范围

第一版要验证：手机触控是否顺手，地层挖掘是否能自然融入消行，以及矿石和深度目标是否让玩家愿意再玩一局。

### 2.1 必须完成

- 一次完整流程：进入首页、阅读简短说明、开始、挖掘、暂停、通关或失败、结算、再次挑战。
- 七种四格方块，包含移动、旋转、软降、硬降、落地锁定、消行、落点虚影、三个后续方块预告和暂存。
- 地层生成与补充，普通消行和地层消除的区别，矿石收集，目标深度判定。
- 一个可重复挑战的关卡；同一关卡的地形、矿石位置和速度曲线固定，方块顺序每局变化。
- 竖屏手机界面、触控按钮、安全区域适配、基础动效和音效。
- 本机最高分、最好用时、矿石收集纪录与声音设置。

### 2.2 后续版本再考虑

多个正式关卡、地图选关、无尽模式、装备、技能、永久成长、岩层耐久、多行遗迹、任务订单、在线排行榜、账号同步、付费和广告均不进入第一版。

第一版的三个地下区域是同一关卡中的视觉与地形变化，不单独作为三个关卡。珍贵矿石提供收集目标，不解锁角色能力。

## 3 页面与单局流程

### 3.1 首页

展示暂定名称、地下矿洞主视觉、关卡目标“向下挖掘30米”、开始按钮、玩法说明入口和声音设置。已有纪录时展示最高分与通关最好用时。

首次开始前，用三幅简短图示说明“落下方块填满一行”“消除带岩石的地层才会增加深度”“矿石所在行消除后即可收集”。说明页可随时从首页重新打开。

### 3.2 对局

开始前显示三秒倒计时。对局中持续展示当前深度与目标、分数、矿石数量、暂存、三个预告和暂停入口。下一块在预告中最突出。

玩家通过触控区操作。每次锁定方块后，依次完成清行、采矿、深度更新、地层补充和状态判断，然后生成下一块。

### 3.3 暂停

手动暂停或页面失去前台状态时，停止重力、操作计时和游戏用时。弹层显示继续、重新开始和返回首页。

继续时倒计时三秒，再恢复操作。重新开始和返回首页会丢失当前进度，需要二次确认；选择取消后仍保持暂停。

电脑辅助操作中，Esc在二次确认页等同取消：返回暂停菜单并保持暂停，不启动恢复倒计时。暂停菜单中的Esc可继续探索，并执行三秒倒计时。

### 3.4 通关与失败

累计清除目标数量的地层行即通关。生成新方块时出生位置被占据，或锁定后仍有方块超出可见棋盘顶部，则失败。失败判断在本次消行和地层补充完成后执行。

同一次结算先达到通关目标时，判定通关，不再继续生成方块。通关与失败均进入结算页，展示深度、分数、矿石、用时和纪录提示，提供再次挑战与返回首页。

## 4 基础方块规则

### 4.1 棋盘与方块

- 棋盘为10列、20个可见行，另有用于出生的隐藏空间。
- 使用I、O、T、S、Z、J、L七种四格方块。每轮将七种各一块随机排序，依次发放后再产生下一轮。
- 方块只能占据空格，不能穿过边界、已落定方块或地层。
- 支持顺时针旋转90度；O形旋转后外观不变。靠墙与贴近地面时，应允许合理的小幅位置修正；各形状的旋转中心与修正表在开发规则表中固定。
- 一行十格全部占满即清除。普通方块、岩石和矿石都作为占据该格处理。
- 清行后，剩余整行向下压实；单个悬空格不额外自由下落，不启用连锁重力。

### 4.2 暂存与预告

预告显示接下来的三个方块。首次暂存将当前方块放入暂存区，并从预告队列取出下一块；之后暂存为交换。每个活动方块最多使用一次暂存，锁定并生成新方块后恢复。

交换出来的方块按初始姿态在出生位置出现。若该位置被占据，则判负。落点虚影始终跟随当前方块的位置和姿态更新。

### 4.3 初始手感参数

以下为原型起始值，试玩后可调整，调整时需同步规则表。

| 参数 | 建议起始值 | 行为 |
| --- | --- | --- |
| 单次左右移动 | 1格 | 按下立即执行 |
| 连续移动启动 | 按住160毫秒 | 到达时长后开始连续移动 |
| 连续移动间隔 | 70毫秒 | 持续按住时重复 |
| 软降间隔 | 60毫秒 | 按住加速下落，松开恢复正常速度 |
| 初始自动下落 | 每900毫秒1格 | 按深度阶段变化 |
| 落地锁定延迟 | 500毫秒 | 接触支撑后仍可短暂调整 |
| 锁定计时重置 | 最多8次 | 仅成功移动或旋转时重置，防止无限拖延 |
| 硬降 | 立即抵达落点并锁定 | 每次按下只触发一次 |

## 5 地层与挖掘规则

### 5.1 深度如何计算

一行预置地下地形称为一行地层，带有独立标记。玩家后来在空中堆成的普通行不带地层标记。

**每清除一行地层，挖掘深度增加1米。清除普通行只计分，不增加深度。** 玩家填入地层缺口的方块不改变这一行的标记。一行含有多块岩石或矿石，也只计1米。

第一关目标暂设为30米，即累计清除30行地层。这里的米数表示已清除地层量，不表示棋盘坐标或曾经触及的最深位置。

### 5.2 初始地层与补充

关卡预先定义30行地层，按由浅到深的顺序排列。开局将最浅的6行放在棋盘底部，其余24行暂不显示。

一次消除中若有k行地层被清除，则在棋盘底部追加最多k行尚未出现的地层。每追加一行，其上的剩余内容整体上移一格，新增行占据最底部。补充发生在清行压实之后，不按时间自行上涨。

因此，在地下储备足够时，棋盘维持6行尚未清除的地层；地层全部显示后不再补充，玩家清完最后几行即可通关。新增行数不超过本次清除的地层行数，补充本身不会额外挤掉棋盘顶部内容。

例：一次同时清除3行，其中2行地层、1行普通行，则深度增加2米，按三行消除计分，并补充最多2行新地层。只消除普通行时，深度不变，也不补充地层。

### 5.3 地形要求

- 每行必须保留缺口，不能生成满行后自动获得进度。
- 第一版每行建议有2至4个空格，缺口连续，避免一格宽的深井。
- 相邻地层的缺口尽量相接，避免多层岩石封住唯一入口。
- 关卡采用固定、人工校验过的地形序列；不承诺任意随机地形都能解。
- 所有矿石应当能随正常地层清除被取得；不设置只能靠未提供技能取得的资源。
- 下层未揭露区域只作为背景，不参与碰撞或计分。

关卡地形矩阵、矿石坐标和至少一条可行操作示例，在开发前单独补为关卡附表。附表未验算前，不把关卡视为已设计完成。

### 5.4 矿石

第一版设铜矿和水晶两种。矿石占据地层中的一个岩石格，碰撞规则与普通岩石相同。所在行清除时自动收集，不需要点击或额外工具；同一行有多颗矿石时逐颗累计。

建议铜矿每颗加50分，水晶每颗加200分。水晶主要放在后半段，数量较少。矿石不是货币，第一版不兑换能力或道具。通关不要求收集指定数量，避免收集目标阻断主流程。

矿石以不同轮廓和纹理区分，不只依赖颜色。结算展示本局收集数及本关总数。

由于第一版通关需要清完全部地层，成功通关时会取得本关所有矿石。矿石在这一版承担探索反馈与失败局进度反馈，不构成可选支线；通关局的成绩差异主要来自多行消除和用时。若后续希望出现“保通关还是冒险拿矿”的选择，需要另行设计可跳过的矿点或其他采矿条件。

## 6 关卡难度与计分

### 6.1 第一关建议参数

| 已挖深度 | 区域 | 自动下落 | 地形重点 |
| --- | --- | --- | --- |
| 0至9米 | 浅层矿道 | 900毫秒每格 | 宽缺口、易识别的铜矿，学习补地层 |
| 10至19米 | 水晶洞 | 750毫秒每格 | 缺口逐渐错位，出现水晶 |
| 20至29米 | 古老岩层 | 600毫秒每格 | 更重视堆叠规划，保持可达路径 |
| 达到30米 | 终点 | 停止 | 通关结算 |

下落速度按已挖深度更新；达到新阶段后，从下一块开始使用新速度。地层的外观按其预设层位显示，背景与区域提示按当前深度切换，允许玩家提前看到少量下一阶段的地层。

不额外叠加按时间加速、限时失败或耐久岩石。单局时长以实测为准，首轮期望控制在约5至10分钟，不作为硬性倒计时。

### 6.2 计分建议

| 一次清除行数 | 基础分 |
| --- | --- |
| 1行 | 100 |
| 2行 | 300 |
| 3行 | 500 |
| 4行 | 800 |

普通行和地层行都参与本次清除行数计算。总分为历次清行基础分、矿石奖励和通关奖励之和；通关奖励暂设1000分。

第一版不加入连击、特殊旋转奖励、背靠背加成、下落距离计分或用时折算，避免评分规则分散注意力。用时单独记录，只有通关成绩参与最快通关纪录。分数不是通关门槛。

## 7 手机操作与界面

### 7.1 竖屏布局

从上到下为：深度目标与暂停入口，分数与矿石等次要信息，棋盘及紧凑的暂存和预告，底部操作区。

之前讨论的电脑左右信息栏改为手机的紧凑布局，不保留大侧栏。棋盘保持1比2的宽高比例，完整显示20行。空间不足时先收起装饰和次要说明，再缩小棋盘；操作区始终可见，不依靠页面滚动操作。

建议至少覆盖360×640、390×844、430×932这三类CSS视口，并处理屏幕刘海、底部手势区域和浏览器工具栏高度变化。关键文字和按钮不能被遮挡。横屏时暂停并提示转回竖屏，不强制申请设备方向权限。

### 7.2 触控区

第一版以可见按钮为主，不引入必须学习的滑动手势。

- 主操作组：左移、软降、右移、旋转；左右移动和软降支持按住。
- 硬降按钮独立放置，与连续移动区域保持间距，标明“落底”。每次按下仅对当前方块生效，下一块出现后必须松手再按才能触发。
- 暂存区可点击，并显示“暂存”文字及本回合是否可用；暂停位于顶部。
- 所有可点击区域至少44×44 CSS像素，主要按钮建议至少48×48。
- 按下有即时视觉反馈，禁用状态能清楚识别。震动仅作为可选增强，不作为操作是否生效的唯一提示。
- 允许按住方向同时点旋转；左右同时按下时，以最后按下的方向为准，释放后按仍被按住的方向恢复。
- 手指滑出按钮、收到触控取消、切出页面或暂停时，立即清除对应按住状态，避免持续误移动。
- 对局区域不触发浏览器滚动、拖拽选择或双击放大；首页与说明页保持正常浏览行为。

左右手布局切换、可拖动按钮和手势操作留待后续试玩判断。

## 8 视觉与声音

### 8.1 视觉基调

精致像素风，深藏蓝和灰紫表现地下空间，暖黄色矿灯提供温度。方块用明亮且克制的配色；岩石用低饱和灰褐色；铜矿和青绿色水晶作为奖励亮点。

棋盘是视觉中心。像素纹理集中在岩壁、矿石、背景和小角色上，活动方块、落点虚影、已落定方块与地层必须能快速区分。文字使用清晰的中文字体，避免小字号像素文字。

方块增加轻微边缘或纹理差异，预告和暂存保持与棋盘相同形状。地层缺口要一眼可见，装饰不得伪装成可碰撞格子。

### 8.2 必要反馈

- 移动和旋转：即时响应，以短促按钮反馈为主。
- 锁定：轻微落定闪光。
- 消行：约200毫秒的裂开与碎屑效果；逻辑只结算一次，效果期间不生成可误操作的下一块。
- 采矿：矿石图标飞向收集位置，表现先后不能影响实际结算。
- 补充地层：短暂平移，位置变化清晰，不使用持续镜头摇晃。
- 区域变化：背景与岩壁柔和过渡，不能遮住落块。
- 通关和失败：清楚显示结果并停止对局输入。

粒子、背景变化和收集动画不阻塞核心操作。暂停时冻结游戏演出；减少动态效果设置关闭强闪光、粒子和镜头位移，保留必要的消行与状态提示。

小矿工属于可删减装饰，只在收获或通关时做简短动作。

### 8.3 声音

需要按钮、锁定、消行、采矿、阶段变化、通关和失败的短音效，背景音乐可后补。声音在玩家主动开始后启用，避免依赖自动播放。提供静音开关并本机保存；任何玩法信息都不能只通过声音传达。

## 9 存储与异常状态

- 本机保存最高分、最深纪录、通关最快用时、最好矿石收集数、声音、减少动态效果与新手说明已读状态。纪录按关卡区分。
- 刷新或关闭页面会结束当前一局，第一版不提供跨刷新续玩。失去前台状态但页面未销毁时自动暂停。
- 本地存储不可用或写入失败时仍可游玩，提示本次纪录可能无法保存。
- 首次加载失败应能重试；素材未就绪前不开始倒计时。第一版不承诺离线访问。
- 返回前台不会立即恢复下落，必须由玩家选择继续。

| 编号 | 场景 | 通过条件 |

| A02 | 触控移动 | 单次移动、按住重复和松开停止正确；取消触控不残留输入 |

| A06 | 普通清行 | 正常计分，深度不变，不补充地层 |
| A07 | 地层清行 | 每清一行地层增加1米，补充数量正确，剩余行位置正确 |
| A08 | 混合清行 | 同时清3行含2行地层时加2米，计500基础分，最多补2行 |
| A09 | 地层尾段 | 总计只出现30行地层，储备耗尽后不补，清完即通关 |
| A10 | 矿石 | 清除所在行才收集，每颗只结算一次，结算数与对局累计一致 |
| A11 | 通关优先 | 达到目标立即通关，不因下一块出生受阻而改判失败 |
| A12 | 堆顶失败 | 消行结算后仍满足失败条件时只弹一次失败结算，不继续落块 |
| A13 | 暂停与切后台 | 重力、游戏用时和按住输入停止，回到前台需主动继续 |
| A14 | 小屏与安全区 | 约定视口内棋盘20行完整可见，按钮可点，无横向滚动或系统遮挡 |
| A15 | 本机纪录 | 刷新后保留设置与纪录；失败局不覆盖通关最快用时 |
| A16 | 声音与弱化动效 | 静音、减少动态效果均生效，不丢失操作与结果信息 |
| A17 | 完整闭环 | 首页到成功、失败、再次挑战各流程都能完成，无无法退出的页面 |

性能验收以实际手机为准：目标设备正常对局时操作反馈及时，消行和补地层无明显卡顿；需要在开发前固定测试机型、浏览器及帧率测量方法，再制定数字门槛。

## 11 开发前需要补齐的内容

### 11.1 当前实现基线

1. 第一版为一个关卡、30米、三段区域。
2. 只有清地层才增加深度，清几行地层就补充最多几行。
3. 矿石用于收集与加分，本版不加入道具和永久成长。
4. 可见按钮作为手机主要操作方式。

本轮按上述四项的建议方案实现。手感参数、速度与分值仍为初始调优值，试玩修改后同步本需求与变更记录。
