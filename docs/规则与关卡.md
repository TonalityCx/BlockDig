# 规则与关卡

适用软件版本：0.1.1。当前可执行配置为 `assets/resources/levels/first-mine.json`。本次修复只涉及暂停确认的键盘操作，规则和地形沿用0.1.0。

## 精确规则

棋盘10列，内部22行；前2行为隐藏出生空间，后20行为可见区域。坐标向右和向下增加。I形使用4×4矩阵，O形使用2×2矩阵，其余使用3×3矩阵。出生姿态为常见的横向基础姿态，矩阵水平居中、左上Y坐标为1。

旋转为顺时针90度；依次尝试相对偏移 `(0,0)、(-1,0)、(1,0)、(-2,0)、(2,0)、(0,-1)、(0,-2)`，第一个可放位置生效，全部受阻则保持原姿态。O形旋转保持原状。这是当前版本明确定义的基础修正规则，不宣称等同其他旋转标准。

落地延迟500毫秒；落地后成功移动或旋转最多重置8次计时。方向按下立即移动，160毫秒后开始每70毫秒重复；软降每60毫秒。硬降每次按下只触发一次，保持按住不会作用于后续方块。暂存每块一次，交换后重置姿态。

锁定后统一找满行。存在满行时进入200毫秒消行动画，此时不接收下一块输入。随后按顺序采矿与计分、移除整行、向下压实、补充地层、增加深度，判定通关优先，再检查隐藏行与出生位置导致的失败。次要粒子不影响数值结算。

一行地层只增加1米，无论该行岩石和矿石数量。普通行不增加深度。开局6行地层，储备总计30行；清k行地层就在底部补最多k行，储备耗尽后不再补。地层标记附着在整行上，补入方块不改变标记。

分数为清1/2/3/4行的100/300/500/800分，铜矿每颗50分、水晶每颗200分，通关再加1000分。

## 确定性可行性验证

随机种子42，使用正式七种方块随机袋、暂存与碰撞规则，在34块后抵达30米，得分6300，收集铜矿10与水晶4。完整操作顺序保存在[通关记录](validation/first-mine-witness.json)，使用 `pnpm verify:level`重放。

记录通过逐步动作执行验证，包含移动、软降、旋转、暂存与硬降，不通过直接填充棋盘完成。它证明指定方块序列下的几何可行性，不证明任意随机序列都能完成，也不包含人的反应时间与触控耗时。实际难度仍需试玩调优。
